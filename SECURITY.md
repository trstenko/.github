# Security

Please report security issues privately to
[security@trstenko.com](mailto:security@trstenko.com). Don't open a public
issue or pull request for them.

Tell us what you found, where (repository, URL or device), and how to
reproduce it. We'll reply within a few days and let you know when it's fixed.

This covers every Trstenko repository, trstenko.com and
voice-collector.trstenko.com.
